# Model order reduction and approximation on general domains in the complex plane
This repository contains the code used for my Ph.D. thesis. 

Each folder indicates the chapter where the code is used. 
Some of the code can be found in the repositories that the author and his co-authors created for the publications that the thesis is based on. 
In particular we have 
- ch3 is based on https://github.com/aaborghi/dd-H2-simplyconnected
- ch4 is based on https://github.com/aaborghi/H2-arbitrary-domains
- ch5 is based on https://github.com/aaborghi/conformalBT
- ch6 is based on https://github.com/pradovera/match_1pEVP

For the experiments to work [chebfun](https://www.chebfun.org) needs to be installed.

NOTE: - the function `ch5/quadconformalBT/trap_rule.md` was taken from [1].

> [1] Reiter, S. (2024). *"Code, Data, and Results for Numerical Experiments in "Generalizations of data-driven balancing: what to sample for different balancing-based reduced models"* (v3). Zenodo. https://doi.org/10.5281/zenodo.14036010
